# Правила работы с проектом SFMShop

## Контекст
SFMShop — учебный проект для освоения профессии Python backend developer. Главная цель — понимание кода и технологий, завершение обучения и подготовка к собеседованиям.

## Правила общения
- Общайся на русском языке.
- Объясняй простыми словами, кратко и поэтапно.
- Один шаг за раз.
- Незнакомые технические термины поясняй.
- При объяснении кода разбирай каждую строку и её назначение.

## Правила работы с кодом
- Перед изменениями объясняй, что собираешься сделать и зачем.
- Не усложняй архитектуру без необходимости.
- Не изменяй файлы, не относящиеся к текущему заданию.
- При выполнении учебных заданий ориентируйся на требования и эталон ментора, если они предоставлены.
- Не читай файлы с секретами, включая .env.
- Не выполняй git commit и git push без моего разрешения.

## Подход к обучению
- Главная задача — не просто написать рабочий код, а понять, как он работает.
- Не переходи к следующему шагу, пока текущий не разобран.
- После завершения темы выделяй 10 ключевых вопросов для повторения по методу «Арена».
